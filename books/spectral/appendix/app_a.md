# 附录 A　符号与单位

| 符号 | 含义 | 单位 |
|:---|:---|:---|
| $\lambda$ | 波长 | nm（公式中的微米另行注明） |
| $\Phi$ | 辐射通量 | W |
| $E$ | 辐照度 | W/m² |
| $I$ | 辐射强度 | W/sr |
| $L$ | 辐亮度 | W/(m²·sr) |
| $L(\lambda)$ | 光谱辐亮度 | W/(m²·sr·nm) |
| $f_r$ | 双向反射分布函数 | sr⁻¹ |
| $T_r$ | 透射率 | 无量纲 |
| $\sigma_a,\sigma_s,\sigma_t$ | 吸收、散射、消光系数 | m⁻¹ 或 mm⁻¹ |
| $\eta$ | 复折射率 $n+ik$，或相对折射率 | 无量纲 |
| $n$ | 折射率 | 无量纲 |
| $V_d$ | 阿贝数 | 无量纲 |
| $\overline{x},\overline{y},\overline{z}$ | CIE 1931 配色函数 | 无量纲 |
| $X,Y,Z$ | 三刺激值 | 无量纲或 cd/m² |
| $x,y,z$ | 色度坐标 | 无量纲 |
| $\mathbf{c}(\lambda)$ | 配色函数向量 $(\overline{x},\overline{y},\overline{z})^{T}$ | 无量纲 |
| $S(\lambda)$ | 光谱功率分布 | W/nm 或相对值 |
| $p(\lambda)$ | 波长的概率密度 | nm⁻¹ |
| $q(\omega\mid\lambda)$ | 方向的概率密度 | sr⁻¹ |
| $\beta$ | 路径 throughput（逐波长） | 无量纲 |
| $R(\lambda_i,\lambda_o)$ | 再辐射矩阵 | 无量纲 |
| $\alpha$ | 单次散射反照率 $\sigma_s/\sigma_t$ | 无量纲 |
| $d$ | 偏振度 | 无量纲 |

几条约定：

可见光区间取 $[380,780]$ nm，涉及紫外荧光时扩展到 $[330,780]$。光谱量一律是"每纳米"的密度，积分时要乘波长微元或除以概率密度。

RGB 一律指线性 RGB（已去掉传递函数）。显示编码与色调映射在最后一步做，不进入渲染循环。

方向用 $\omega$ 表示，立体角微元 $d\omega$，半球记作 $H^2$。入射下标 $i$，出射下标 $o$。

概率密度统一用 $p$，上下文说明是对波长、方向还是面积。多波长路径里第 $i$ 个波长的边际密度记作 $p_i$。

玻璃名称用 Schott 的商品名：N-BK7（冕牌）、F2、SF11（火石），另加熔石英。Sellmeier 系数见附录 B。
