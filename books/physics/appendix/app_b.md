# 附录 B　常数与单位换算

## B.1 基本物理常数

下表取自 CODATA 2018 推荐值。2019 年国际单位制改版之后，带"精确"二字的量按定义固定，不再有不确定度。

| 量 | 符号 | 数值 | 单位 |
|---|---|---|---|
| 真空中光速 | $c$ | $299792458$（精确） | $\mathrm{m\,s^{-1}}$ |
| 真空介电常数 | $\varepsilon_0$ | $8.8541878128\times10^{-12}$ | $\mathrm{F\,m^{-1}}$ |
| 真空磁导率 | $\mu_0$ | $1.25663706212\times10^{-6}$ | $\mathrm{H\,m^{-1}}$ |
| 库仑常数 | $k=1/(4\pi\varepsilon_0)$ | $8.9875517923\times10^{9}$ | $\mathrm{N\,m^2\,C^{-2}}$ |
| 基本电荷 | $e$ | $1.602176634\times10^{-19}$（精确） | $\mathrm{C}$ |
| 普朗克常数 | $h$ | $6.62607015\times10^{-34}$（精确） | $\mathrm{J\,s}$ |
| 电子质量 | $m_e$ | $9.1093837015\times10^{-31}$ | $\mathrm{kg}$ |
| 质子质量 | $m_p$ | $1.67262192369\times10^{-27}$ | $\mathrm{kg}$ |
| 阿伏伽德罗常数 | $N_A$ | $6.02214076\times10^{23}$（精确） | $\mathrm{mol^{-1}}$ |
| 玻尔兹曼常数 | $k_B$ | $1.380649\times10^{-23}$（精确） | $\mathrm{J\,K^{-1}}$ |
| 万有引力常数 | $G$ | $6.67430\times10^{-11}$ | $\mathrm{N\,m^2\,kg^{-2}}$ |
| 电子伏特 | $\mathrm{eV}$ | $1.602176634\times10^{-19}$（精确） | $\mathrm{J}$ |
| 原子质量单位 | $\mathrm{u}$ | $1.66053906660\times10^{-27}$ | $\mathrm{kg}$ |

由表里的值可以算出两个常用组合。第一个是

$$\frac{1}{\sqrt{\varepsilon_0\mu_0}}=299792458\ \mathrm{m\,s^{-1}} , \tag{B.1}$$

这正是光速，第二十七章会推这个式子。第二个是

$$\frac{\mu_0}{4\pi}=1.00000000055\times10^{-7}\ \mathrm{H\,m^{-1}} , \tag{B.2}$$

2019 年以前这个数被定义为精确的 $10^{-7}$，改版之后 $\mu_0$ 变成实验值，与 $10^{-7}$ 的偏差在小数点后第十位，本书的计算一律取 $4\pi\times10^{-7}$。

## B.2 国际单位制

七个基本单位：

| 量 | 单位 | 符号 | 定义依据 |
|---|---|---|---|
| 长度 | 米 | m | 光在 $1/299792458$ 秒内走过的距离 |
| 质量 | 千克 | kg | 普朗克常数取 $6.62607015\times10^{-34}\ \mathrm{J\,s}$ |
| 时间 | 秒 | s | 铯 133 原子特定跃迁频率的 $9192631770$ 个周期 |
| 电流 | 安培 | A | 基本电荷取 $1.602176634\times10^{-19}\ \mathrm{C}$ |
| 温度 | 开尔文 | K | 玻尔兹曼常数取 $1.380649\times10^{-23}\ \mathrm{J\,K^{-1}}$ |
| 物质的量 | 摩尔 | mol | 阿伏伽德罗常数取 $6.02214076\times10^{23}$ |
| 发光强度 | 坎德拉 | cd | 给定频率的单色光源的光效率 |

电磁学用到的导出单位：

| 量 | 单位 | 符号 | 用基本单位表示 |
|---|---|---|---|
| 力 | 牛顿 | N | $\mathrm{kg\,m\,s^{-2}}$ |
| 功、能量 | 焦耳 | J | $\mathrm{N\,m}=\mathrm{kg\,m^2\,s^{-2}}$ |
| 功率 | 瓦特 | W | $\mathrm{J\,s^{-1}}$ |
| 电荷 | 库仑 | C | $\mathrm{A\,s}$ |
| 电势 | 伏特 | V | $\mathrm{J\,C^{-1}}=\mathrm{W\,A^{-1}}$ |
| 电场强度 | 伏特每米 | $\mathrm{V\,m^{-1}}$ | $\mathrm{kg\,m\,s^{-3}\,A^{-1}}$ |
| 电容 | 法拉 | F | $\mathrm{C\,V^{-1}}=\mathrm{A^2\,s^4\,kg^{-1}\,m^{-2}}$ |
| 电阻 | 欧姆 | $\Omega$ | $\mathrm{V\,A^{-1}}$ |
| 磁感应强度 | 特斯拉 | T | $\mathrm{V\,s\,m^{-2}}=\mathrm{kg\,s^{-2}\,A^{-1}}$ |
| 磁通量 | 韦伯 | Wb | $\mathrm{T\,m^2}=\mathrm{V\,s}$ |
| 电感 | 亨利 | H | $\mathrm{Wb\,A^{-1}}=\mathrm{V\,s\,A^{-1}}$ |

两个容易混的单位是特斯拉和韦伯。特斯拉描述磁场的强弱，韦伯描述穿过一个面的磁通量，一韦伯等于一特斯拉乘一平方米。

## B.4 单位换算

| 换算 | 关系 |
|---|---|
| 电子伏特与焦耳 | $1\ \mathrm{eV}=1.602176634\times10^{-19}\ \mathrm{J}$ |
| 埃与米 | $1\ \mathrm{\mathring{A}}=10^{-10}\ \mathrm{m}$ |
| 高斯与特斯拉 | $1\ \mathrm{G}=10^{-4}\ \mathrm{T}$ |
| 奥斯特与安培每米 | $1\ \mathrm{Oe}=1000/(4\pi)\ \mathrm{A\,m^{-1}}\approx79.577\ \mathrm{A\,m^{-1}}$ |
| 卡与焦耳 | $1\ \mathrm{cal}=4.184\ \mathrm{J}$ |
| 千瓦时与焦耳 | $1\ \mathrm{kW\,h}=3.6\times10^{6}\ \mathrm{J}$ |
| 标准大气压 | $1\ \mathrm{atm}=1.01325\times10^{5}\ \mathrm{Pa}$ |

高斯制与 SI 的差别不只是单位倍数。在高斯制里库仑定律写成 $F=q_1q_2/r^2$，不出现 $4\pi\varepsilon_0$，于是电场和磁场的量纲相同，麦克斯韦方程组里 $c$ 出现在旋度方程中。第二十八章给出两套写法之间的逐项对照。
