# 附录 B　符号表

全书的符号前后一致。同一符号在不同章里含义相同，除非该章特别说明。

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $d(\mathbf{p})$ | 有符号距离，内部为负 | 长度 |
| $f(\mathbf{p})$ | 场的值，可能是近似距离 | 长度 |
| $S$ | 曲面（表面） | — |
| $\Omega$ | 曲面围住的内部 | — |
| $\mathbf{n}$ | 单位法线 | 无量纲 |
| $\mathbf{s}^*$ | 最近点 | 位置 |
| $\mathbf{u},\omega$ | 单位方向 | 无量纲 |
| $t$ | 沿光线的参数，或偏移量 | 长度 |
| $h$ | 体素边长，或差分步长 | 长度 |
| $k$ | 平滑参数，或软阴影的放大常数 | 长度 / 无量纲 |
| $w$ | 窄带宽度，或密度过渡带宽度 | 长度 |
| $r$ | 半径 | 长度 |
| $\kappa$ | 曲率，主曲率 | 长度的倒数 |
| $L$ | 场梯度的上界，或场景边长 | 无量纲 / 长度 |
| $\sigma_t,\sigma_s,\sigma_a$ | 消光、散射、吸收系数 | 长度的倒数 |
| $T$ | 透射率 | $[0,1]$ |
| $A$ | 环境光遮蔽的可见性，或表面积 | $[0,1]$ / 面积 |
| $\epsilon$ | 步进的终止精度 | 长度 |
| $\lambda$ | 正则项权重 | 无量纲 |

几个容易混的地方单独说明。

$h$ 在讲网格时是体素边长，在讲差分时是步长。两者都是"长度的离散化尺度"，含义一致，但数值可能相差几个数量级：体素边长是毫米，差分步长是微米。

$k$ 在讲平滑并集时是长度的量纲（圆角半径约 $0.85k$），在讲软阴影时是无量纲的放大常数。正文里上下文总能区分：出现 $k$ 的式子里若还有距离量，它就是长度。

$L$ 既是场梯度的上界，也是场景的边长。前者出现在第 9 章，后者出现在第 15 章，两处不同时出现。

$A$ 既是可见性，也是表面积。第 11 章的 $A(\mathbf{p})$ 带位置参数，是可见性；第 15 章的 $A$ 不带参数，是表面积。

$t$ 在距离场里是偏移量（壳体厚度），在光线里是参数。两者的量纲相同，都用长度。
