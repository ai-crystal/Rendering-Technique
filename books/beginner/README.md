# 材质渲染的骨架

> 微表面、Fresnel、能量补偿、分层与采样

作者：Dr. Dezeming　　在线阅读 <https://ai-crystal.github.io/Rendering-Technique/>　　下载：[整本 PDF](https://github.com/ai-crystal/Rendering-Technique/raw/main/output/rendering-00-beginner.pdf)

一个材质为什么长成那个公式，公式里每一项在物理上对应什么，换一种材料时哪一条假设先碎——这是后面八册反复要问的三个问题。 入门篇把公共语言搭起来：Fresnel、微表面三段式、丢失的能量、分层界面、采样与验证。读完能自己写出一个能量守恒、能被采样的 BSDF，也知道怎么证明它是对的。
