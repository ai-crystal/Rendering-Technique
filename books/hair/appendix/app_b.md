# 附录 B　毛发参数速查

这一页把散在各章的典型值集中起来，方便实现时查。表中标注"量级"的数值是估值，用于开始时给一个合理起点，不是测量结果。

## 几何与光学常数

| 量 | 典型值 | 说明 |
|----|--------|------|
| 纤维半径 $R$ | 30–50 微米 | 亚洲人偏粗，可达 60 微米；欧洲人偏细 |
| 截面长短轴比 | 1.1–1.4 | 越扁越容易出现转头时的亮带扫过 |
| 角质层厚度 | 0.1R 量级 | 6 到 10 层鳞片 |
| 鳞片倾角 | 2°–5° | 标准差取 0.03–0.08 rad |
| 折射率 $\eta$ | 1.55 | 波长相关，可见光范围内变化约 0.01 |
| 垂直入射反射率 | 4.6% | 由 $\eta$ 直接算出 |

## 散射模型参数

| 量 | 典型值 | 影响 |
|----|--------|------|
| 粗糙度 $\beta$ | 0.12–0.18（健康） | 高光宽度，半高宽约 $2.355\beta$ |
| | 0.25–0.35（造型受损） | |
| | 0.5 以上（漂过） | 高光糊成一片 |
| 平均内反射率 | 0.2–0.4 | 决定高阶路径的能量，深色头发取低值 |
| TRT 折返角 | 18°（$\eta=1.55$） | 第二道高光的位置 |
| 折返点 $h^\ast$ | 0.73 | 由 $\sqrt{(4-\eta^2)/3}$ 给出 |

## 黑色素吸收系数

取自 PBRT 中的系数集，单位是"每单位直径"，配合以直径为单位计量的路径长度使用。

| 类型 | 红 | 绿 | 蓝 |
|------|-----|-----|-----|
| 真黑色素 | 0.419 | 0.697 | 1.37 |
| 褐黑色素 | 0.187 | 0.400 | 1.05 |

有效系数按褐黑比例插值：

$$\sigma_a=\left[(1-r)\,\sigma_{\text{eum}}+r\,\sigma_{\text{pheo}}\right]c , \tag{B.1}$$

$r$ 是褐黑比例，$c$ 是浓度。

| 发色 | 浓度 $c$ | 褐黑比例 $r$ |
|------|-----------|---------------|
| 浅金 | 0.05–0.12 | 0.1–0.3 |
| 金 | 0.12–0.25 | 0.2–0.4 |
| 棕 | 0.30–0.50 | 0.1–0.3 |
| 黑 | 0.80–1.20 | 0–0.1 |
| 红 | 0.30–0.50 | 0.7–1.0 |

## 体积化参数

| 量 | 典型值 | 说明 |
|----|--------|------|
| 纤维密度 $\rho$ | 100–300 m/cm³ 量级 | 取决于发型与蓬松度 |
| 单次散射反照率 $\varpi$ | 0.95（浅）–0.3（深） | 与浓度直接相关 |
| 各向异性 $g$ | 0.6–0.8 | 前向散射 |
| 切换到体积的阈值 | 每像素 20 根以上 | 低于此值会看到"少了丝" |

## 数值容差

| 检查项 | 容差 | 依据 |
|--------|------|------|
| 白炉积分 | 1% | 能量误差会随反弹累积 |
| 求交位置误差 | $R/50$ | 对应 1 度的法线误差 |
| 折线每段转角 | 1 度 | 超过会看到高光断裂 |
| 方位角表格子 | 0.5 度 | 再细无可见差别 |
| 路径长度用平均值 | 3% | 圆截面下实测不到 1% |
