# 附录 A　符号表

| 符号 | 含义 | 单位或取值 |
| --- | --- | --- |
| $n$ | 折射率实部 | 无量纲 |
| $k$ | 消光系数 | 无量纲 |
| $\tilde n$ | 复折射率 $n+\mathrm{i}k$ | 无量纲 |
| $w=a+\mathrm{i}b$ | 复数 Snell 定律中的 $\tilde n\cos\theta_t$ | 无量纲 |
| $F_0$ | 垂直入射的反射率 | $[0,1]$ |
| $F(\theta)$ | 角度相关的 Fresnel 反射率 | $[0,1]$ |
| $F_{\text{avg}}$ | Fresnel 的余弦加权平均 | $[0,1]$ |
| $\delta$ | 趋肤深度 $\lambda/4\pi k$ | nm |
| $\lambda$ | 真空波长 | μm 或 nm |
| $n,\ t,\ b$ | 法线、切线、副切线 | 单位向量 |
| $h$ | 半程向量，$\omega_i+\omega_o$ 归一化 | 单位向量 |
| $\theta_h,\ \phi_h$ | 半程向量的天顶角、方位角 | rad |
| $m_x,\ m_y$ | 表面坡度，$\tan\theta_h\cos\phi_h$ 等 | 无量纲 |
| $D(h)$ | 法线分布函数 | $\mathrm{sr^{-1}}$ |
| $G_1,\ G_2$ | 单侧与双侧遮蔽函数 | 无量纲 |
| $\Lambda$ | Smith 的 $\Lambda$ 函数 | 无量纲 |
| $a_x,\ a_y$ | 两个切线方向的粗糙度参数 | $>0$ |
| $\alpha_o$ | 投影粗糙度 | $>0$ |
| $f_r$ | BRDF | $\mathrm{sr^{-1}}$ |
| $f_{ss},\ f_{ms}$ | 单次散射与多次散射项 | $\mathrm{sr^{-1}}$ |
| $E(\mu,\phi)$ | 单次散射方向反照率 | $[0,1]$ |
| $E_{\text{avg}}$ | $E$ 的半球平均 | $[0,1]$ |
| $\mu_i,\ \mu_o$ | $\cos\theta_i$、$\cos\theta_o$ | $[0,1]$ |
| $A,\ B$ | split-sum 的两个预积分项 | 无量纲 |
| $d$ | 膜厚 | nm |
| $n_1$ | 膜的折射率 | 无量纲 |
| $\delta_{\text{film}}$ | 膜内单程相位 $2\pi n_1d/\lambda$ | rad |
| $L_c$ | 相干长度 $\lambda^2/\Delta\lambda$ | nm |
| $r_{01},\ r_{12}$ | 两个界面的振幅反射系数 | 复数 |
| $\sigma_d$ | 膜厚的均方根起伏 | nm |
