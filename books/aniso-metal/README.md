# 各向异性金属

> 复折射率、各向异性 GGX、拉丝与氧化层

作者：Dr. Dezeming　　在线阅读 <https://ai-crystal.github.io/Rendering-Technique/>　　下载：[整本 PDF](https://github.com/ai-crystal/Rendering-Technique/raw/main/output/rendering-05-aniso-metal.pdf)

金属的反射率随波长变化，这不是调色能还原的：铜偏红、金偏黄、铝几乎中性，原因是自由电子对不同频率的响应不同。更麻烦的是拉丝表面——高光被拉成一条线，而不是一个圆斑。 这本书从复折射率与导体 Fresnel 出发，把微表面理论推广到各向异性，再讲拉丝、锤纹、氧化层与薄膜，最后落到实时管线里能用的近似。
