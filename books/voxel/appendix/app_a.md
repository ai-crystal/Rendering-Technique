# 附录 A　符号表

全书的符号保持前后一致。同一符号在不同章里含义相同，除非该章特别说明。

| 符号 | 含义 | 单位或取值 |
|---|---|---|
| $h$ | 体素边长 | m |
| $N$ | 单轴的格数，分辨率记为 $N^3$ | 无量纲 |
| $L$ | 八叉树的深度，或 mip 层级的最大编号 | 无量纲 |
| $l$ | 某一层的编号 | $0\le l\le L$ |
| $A$ | 表面积 | m$^2$ |
| $V$ | 体积 | m$^3$ |
| $P$ | 周长或轮廓总长 | m |
| $o(x)$ | 占据率，二值或分数 | $[0,1]$ |
| $f(x)$ | 有符号距离，内部为负 | m |
| $n$ | 法线 | 单位向量 |
| $\alpha$ | GGX 的粗糙度参数 | $(0,1]$ |
| $\theta$ | 锥的半角，或入射角 | rad 或度 |
| $\delta$ | 法线误差角 | 度 |
| $r(t)$ | 锥在距离 $t$ 处的半径 | m |
| $T$ | 透射率，穿过的能量比例 | $[0,1]$ |
| $\rho$ | 反照率 | $[0,1]$ |
| $E$ | 辐照度 | W m$^{-2}$ |
| $L_i,L_o$ | 入射与出射辐亮度 | W m$^{-2}$ sr$^{-1}$ |
| $V$ | 可见性函数，或球谐系数 | $[0,1]$ |
| $c_{lm}$ | 球谐系数 | 视基函数而定 |
| $\hat A_l$ | 球谐域里 clamped cosine 的卷积系数 | $\pi,\ 2\pi/3,\ \pi/4$ |
| $\sigma$ | 噪声标准差 | 与被测量同 |

几个容易混淆的地方单独说明。

$L$ 在两个地方出现，八叉树的深度和 mip 层级的上限，两者的含义是一致的，因为 mip 链的层数就是树的深度加一。$l$ 既可以指树的层，也可以指 mip 层，编号都从 0 开始，0 是最细的一层。

$V$ 既用来表示体积，也用来表示可见性。正文里凡是出现 $V$ 的地方，若后面跟的是括号和方向，就是可见性；若出现在体积公式里，就是体积。附录里这样含糊是不好的，但正文里两者从不同时出现在同一个式子里。

$E$ 有两个用法，辐照度和能量。第 5 章讲辐照度，第 9 章讲白炉测试时用的是总能量，那里的 $E_k$ 是一个归一化的比例，不带量纲。

$\theta$ 在讲锥的时候是半角，在讲 Fresnel 和余弦的时候是夹角。两者的定义都是"两个方向之间的角度"，数值范围都是 $[0,\pi/2]$，所以共用同一个符号不会出错。
